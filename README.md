## Portfolio philosophy

The project repositories use an explicit provenance standard:

- **RECOVERED** — supported by prior work, records, or artifacts;
- **RECONSTRUCTED** — faithfully rebuilt where original source bytes were unavailable;
- **ENHANCED** — modern engineering improvements added for portfolio quality;
- **UNVERIFIED** — not presented as historical fact without supporting evidence.

This keeps the portfolio technically useful without overstating what can be established from the original project artifacts.
